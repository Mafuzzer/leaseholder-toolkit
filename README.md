# Leaseholder Toolkit

A comprehensive resource for UK leaseholders navigating service charge disputes and tribunal proceedings.

## Contents

- **Case Study:** Detailed documentation of one leaseholder's 18-month tribunal dispute (LON/00AX/LSC/2025/0637)
- **Toolkit PDF:** 92-page guide through the entire dispute process, from recognition to recovery
- **Claude Skill:** Conversational AI assistant for real-time guidance (optional)

## About

This project documents the practical reality of challenging unreasonable service charges in England and Wales. The case study provides a factual account of the process, timeline, and outcomes. The toolkit offers phase-by-phase guidance for others facing similar disputes.
